# 古诗词图像化学习工具 - 前端

## 项目介绍

本前端应用是古诗词图像化学习系统的用户界面，提供直观的交互方式让用户将古诗词/古文转化为可视化的故事书或连环画。通过 AI 驱动的图像生成技术，帮助学生更好地理解和记忆古诗词内容。

## 主要功能

### 内容创作

- **文本输入**：支持直接输入古诗词或古文内容
- **图片参考**：支持上传参考图片影响生成风格
- **模式选择**：故事书 (storybook) 和连环画 (comics) 两种生成模式
- **生成类型**：支持图像生成和视频生成两种类型
- **尺寸设置**：可选择 9:16 或 16:9 等多种图片比例
- **视频配置**：支持设置视频时长、帧率、宽高比等参数
- **实时预览**：生成过程中实时展示进度和结果
- **古风Loading**：视频生成时显示古风韵味的等待动画，包含进度、步骤和诗句提示

### 诗词雅集（古诗词库）

- **分级浏览**：类型 → 版本 → 年级 → 学期 四级树形导航
- **快速搜索**：按标题、作者、内容关键词搜索
- **一键选用**：点击诗词卡片自动填入输入框
- **自定义收藏**：添加和管理用户自定义诗词

### 墨迹留痕（作品管理）

- **自动保存**：成功生成的作品（图像/视频）自动保存
- **卡片预览**：封面、标题、时间一目了然
- **便捷操作**：编辑标题、查看详情、删除作品
- **视频支持**：支持视频作品的预览、下载和全屏播放
- **历史迁移**：自动将历史生成记录迁移到作品库

### 历史记录

- **会话管理**：保存每次对话记录
- **快速恢复**：点击历史记录恢复之前的对话
- **时间显示**：完整的年月日时分显示

## 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Modern.js
- **样式方案**：Tailwind CSS + Less Modules
- **UI 组件**：Arco Design
- **状态管理**：React Hooks + LocalStorage
- **日期处理**：Day.js

## 环境要求

- Node.js 22+（推荐使用项目指定的版本，详见 .nvmrc）
- pnpm 9+ 包管理器

## 开发流程

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
pnpm dev
```

服务启动后，默认访问 `http://localhost:3000`。

### 构建生产版本

```bash
pnpm build
```

### 本地预览生产构建

```bash
pnpm serve
```

## 数据存储

前端使用 LocalStorage 进行客户端数据持久化：

| Key | 说明 |
|-----|------|
| `chat_history` | 聊天历史记录 |
| `generation_records` | 生成作品记录（图像） |
| `video_generation_records` | 视频生成记录 |
| `custom_poetry_list` | 用户自定义诗词 |

## 性能优化

### 智能轮询机制

- **视频生成任务**：使用动态轮询间隔（10-20秒），根据等待时间自动调整
- **活跃任务检查**：仅在存在活跃任务时定期检查（每5秒），无任务时完全停止
- **进度更新优化**：仅在进度变化超过5%或状态变化时更新UI，减少不必要的渲染

### 请求频率控制

- 图像生成任务：2秒轮询间隔
- 文本分析任务：1.5秒轮询间隔
- 视频生成任务：10-20秒动态间隔
- 活跃任务检查：有任务时5秒，无任务时停止

### 用户体验优化

- **古风Loading动画**：视频生成时显示古风韵味的等待界面
  - 实时进度条显示
  - 步骤提示（研墨调色、笔走龙蛇、渲染着色、装裱成卷）
  - 随机古风诗句展示
  - 动态提示语（根据等待时间显示不同内容）
  - 等待时间显示（古风表达：已过X息/X刻）

## 安全性

- **日志控制**：生产环境不输出调试信息和敏感数据
- **错误处理**：静默处理错误，避免暴露内部信息
- **数据验证**：所有用户输入进行验证和清理

## 注意事项

- 确保后端服务已正常启动（默认 `http://127.0.0.1:8000`）
- 生成内容需要火山引擎 API，确保后端已配置相关密钥
- 浏览器需支持 LocalStorage 以保存历史记录和作品
- 视频生成时间较长（通常需要几分钟），请耐心等待
